# GUI Technologies — CCTV Manager Pro

A standalone CCTV breakdown, site visit and installation project management web application.

## Planned roles
- Admin: user management, all jobs, reports and settings
- Office staff: customers, job intake, scheduling and assignments
- Technician: assigned jobs and progress updates

## Planned stack
Next.js, Supabase Auth + PostgreSQL (RLS), Vercel.

## Security
This repository is currently public. Do not commit credentials, customer information, database exports, or production environment variables. A dedicated database is not yet provisioned; do not run the schema in the existing My Solution Colombo or attendance databases.

## Status
Initial project scaffold; not deployed or production-ready.
